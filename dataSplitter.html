常用正則表示式對照表

表示式 說明
.任意單一字元（不含換行）
\d數字（0-9）
\D非數字
\w英文字母、數字或底線
\W非英數字與底線
\s空白字元（空格、Tab、換行）
^字串起始位置
$字串結尾位置
*前一字元出現 0 次或多次
+前一字元出現 1 次或多次
?前一字元出現 0 或 1 次
{n}恰好 n 次
{n,}至少 n 次
{n,m}n 到 m 次
[abc]a 或 b 或 c
[^abc]非 a、b、c
[a-z]任一小寫英文字母
(...)群組（可重複引用）
a|ba 或 b
\b字邊界（單字開頭／結尾）
